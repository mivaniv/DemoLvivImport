# Як оновлюється каталог на lvivimport.com (чинний сайт, WordPress)

Стан на 26.10.2026. Зібрано з налаштувань WP All Import і кронів DirectAdmin. Адреса файлу вивантаження й ключ запуску імпорту навмисно не наводяться: репозиторій публічний, а у файлі є всі оптові ціни.

## Схема

```
1С ──(щоночі, ~05:10)──▶ файл вивантаження на сервері lvivimport.com
                         фото ──▶ wpallimport/files/images_backup/<код>-<N>.jpeg
                                    │
WP All Import, імпорт №2 «Categories» (06:40) ──▶ 69 категорій WooCommerce
        └─ після завершення сам запускає імпорт №1 (хук pmxi_after_xml_import)
WP All Import, імпорт №1 «Products Import» (07:10) ──▶ ~1200 товарів WooCommerce
```

Сайт: WordPress 6.0, WooCommerce, WPML 4.5.8 (8 мов), тема Oxygen, тека `wp-content` перейменована на `assets`.

## Крони (DirectAdmin → Cron Jobs)

| Розклад | Що запускає |
| --- | --- |
| `40 6 * * *` | trigger імпорту №2 «Categories» |
| `10 7 * * *` | trigger імпорту №1 «Products Import» (дублює ланцюжок: №2 сам запускає №1) |
| `* * * * *` ×2 | processing обох імпортів — обробка частинами, поки імпорт не завершиться |
| `* 7 * * *` | `assets/uploads/wpallimport/create-backup.php` — **щохвилини з 07:00 до 07:59** (60 разів; ймовірно, мало бути `0 7 * * *`) |

## Файл вивантаження (`<goods>`)

**Категорії** (`<categories><cat>`): `name` (з номером-префіксом для сортування, напр. «12.КАВА І ЧАЙ»), `slug`, `category_id` (UUID з 1С), `parent_id`, `level` (0–2), `in_price`.

**Товари** (`<products><product>`):

| Поле | Значення | Як використовує WordPress |
| --- | --- | --- |
| `uuid` | ID товару в 1С | ключ зіставлення |
| `code` | код 1С, напр. `00-00001456` | артикул (SKU), назва фото |
| `name`, `description`, `barcode` | назва, опис, штрихкод | як є |
| `category`, `category_id` | назва й UUID категорії | `catId()` шукає категорію за мета-полем `uuid` |
| `qty` | штук у ящику | множник ціни ящика |
| `ammount` | 1 — є в наявності, 0 — немає | `stockStatus()` → instock / outofstock |
| `price_tier_0…23` | ціни за штуку для різних типів цін 1С | ціна товару = `price_tier_1 × qty` (`boxPrice()`) |
| `discount`, `sale_pice` | акція й акційна ціна за штуку | акційна ціна = `sale_pice × qty` (`salePrice()`) |
| `top`, `new`, `discount`, `from_piece` | позначки 1/0 | мітки `top`, `new`, `sale`, `from-piece` |
| `images/image` | назви файлів, кілька — через кому | `productImage()` → URL у `images_backup` |

Назви категорій: номер-префікс прибирається, регістр — «Перша велика» (`catname()`). Товари MESSIS сортуються першими (`order_by_category()`).

## Фото

- У файлі лише назви: `00-00001456-1.jpg`.
- `productImage()` бере **лише перше** фото, міняє `jpg`/`png` на `jpeg` і додає адресу теки `https://lvivimport.com/assets/uploads/wpallimport/files/images_backup/`.
- WP All Import завантажує фото за цією адресою в медіатеку, але спершу шукає в медіатеці файл з такою самою назвою й використовує його повторно. Тому в нових товарів бувають фото з 2023 року.
- Друге й наступні фото товару на сайт не потрапляють.

## Що зникає з файлу

- Товари, яких немає у файлі, імпорт №1 переносить **у кошик** (26.10: 15 товарів).
- Категорії, яких немає у файлі, імпорт №2 **видаляє назавжди**.

## Як це перенести на демосайт

Наш імпортер ([src/importer/](../src/importer/)) працює за тією ж логікою: повне вивантаження, приховування відсутніх товарів, фото за прямим посиланням. Формат `<goods>` розбирає [adapters/goods.ts](../src/importer/adapters/goods.ts):

- `uuid` → `id`, `code` → `sku`, `qty` → `unitsPerBox`, `ammount` → `inStock`;
- `top`/`new`/`discount` → `popular`/`isNew`/`sale`, `from_piece` → «Від 1 шт»;
- `price_tier_<N>` → ціна, тип ціни задається змінною `IMPORT_PRICE_TYPE`;
- фото — за тим самим правилом, що `productImage()`, але з усіма фото, а не лише першим;
- бренд — з підкатегорії або першого слова розділу, якщо воно є в назві товару окремим словом (Макарони > Tomadini → Tomadini).

Адреса файлу задається змінною `IMPORT_SOURCE_URL` на сервері, у репозиторій не потрапляє.
